## What Is a World Model?

"World model" is overloaded term and a huge buzz word today. It refers to a simulator/dynamics model and can refer to different things:

| Type | What it predicts | Example |
|------|------------------|---------|
| Tabular dynamics model | Next state and reward from observed counts | Dyna-Q |
| Neural latent dynamics model | Future latent state and reward | Dreamer |
| Planning model | Reward, value, and policy-relevant latent dynamics | MuZero |
| Interactive generative world | Action-conditioned future observations | Genie, Minecraft world models |

The important idea:

> A world model does not have to perfectly reconstruct the world. It has to preserve enough structure for the agent to choose better actions.

In some settings, a rough simulator is enough. In others, even small errors can change the policy the agent learns. 
The challenge is not just asking how accurate the simulator is overall, but asking whether its errors occur in parts of the environment that matter for decision-making. 
This is related to the **value equivalence principle** (Grimm et al., 2020): a model does not need to perfectly predict every future state transition to be useful. 
It can still support effective planning if it induces the same value-relevant Bellman updates as the real environment for the policies and value functions the agent actually uses.

<Callout type="tip" title="Takeaway">
A world model is not necessarily a "video generator". I's a **consequence model**, only needing to preserve the parts of the future that matter for action.
</Callout>

In the diagnostic workup exercise below, the world model is deliberately minimal with count-based estimates of P̂(s' | s, a) and R̂(s, a) over **information states** (what the clinician has observed so far). The model learns what tends to happen when you order a test or commit to a diagnosis, even though the true disease label is hidden.
