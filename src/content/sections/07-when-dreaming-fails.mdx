## When Dreaming Fails

The danger is that the agent can overfit to its dream.

If the learned transition model predicts that moving right from a wall sometimes teleports the agent closer to the goal, Q-learning has no way to know that the transition is fake during imagined updates. The value function will assign credit to actions that only work inside the model.

This is **model exploitation**. The agent does not become irrational. It becomes rational with respect to the wrong world.

We simulate this by injecting **transition noise**: with some probability, imagined next states are replaced by random valid cells. The agent still performs imagined updates; it just learns from corrupted dynamics.

<DynaResultCharts variant="returnVsNoise" />

As model noise increases, final performance drops even though dreaming budget stays at `k = 20`. More dreaming helps only while model error is low enough.

<Callout type="warning" title="Takeaway">
More imagined updates amplify both good and bad models. A wrong model does not confuse the agent — it gives the agent a different environment to optimize.
</Callout>

Try the GridWorld interactive explorer (section 5) with model noise turned up. The heatmap may look optimistic while real performance collapses. The diagnostic workup section shows the same amplification with D-dimer model bias.
